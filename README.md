# کاوش 3.4 — دستیار هوشمند عمومی

کاوش دیگر محدود به سلامت نیست. هستهٔ آن برای آموزش، ریاضی، علوم، زبان، برنامه‌نویسی، نوشتن، تحلیل و گفت‌وگوی عمومی طراحی شده است.

## ویژگی‌های جدید (۳.۴)
- **حافظه چت پایدار**: تاریخچه گفتگو در مرورگر (localStorage) ذخیره می‌شود و بعد از بستن/باز کردن صفحه حفظ می‌ماند.
- دکمه «پاک کردن» برای حذف کامل تاریخچه.
- بهبود ساخت تصویر و ویدیو (نمایش وضعیت + دانلود).
- پشتیبانی کامل از PWA (آیکون‌ها و Service Worker).

## مدل‌ها
- آستارا: OpenAI → Anthropic (در صورت تنظیم کلیدها)
- لایت: DeepSeek → xAI
- MIOS: Gemini

## اجرا
1. Node.js 18+ نصب کنید.
2. `.env.example` را به `.env` تبدیل کنید و کلیدهای API را وارد کنید.
3. `npm start`
4. مرورگر را روی `http://localhost:3000` باز کنید.

کلیدها فقط روی سرور قرار می‌گیرند و به کلاینت ارسال نمی‌شوند.

## ریاضی فارسی
عبارت‌هایی مانند `۲ جمع ۳`، `۲۰ منهای ۷`، `۱۲ ضربدر ۴` و `۱۰ تقسیم بر ۲` مستقیماً پردازش می‌شوند.

## امنیت
فیلتر فقط روی چند دستهٔ مشخص از درخواست‌های واقعاً خطرناک/سوءاستفاده‌گرانه فعال است و محتوای آموزشی عادی را مسدود نمی‌کند.

## تنظیم API Key
فایل `.env` را کنار `server.js` بسازید و کلیدها را در آن قرار دهید:

```env
OPENAI_API_KEY=کلید_OpenAI
ANTHROPIC_API_KEY=کلید_Anthropic
# اختیاری:
DEEPSEEK_API_KEY=
XAI_API_KEY=
GEMINI_API_KEY=
OPENROUTER_API_KEY=
TAVILY_API_KEY=
REPLICATE_API_TOKEN=          # برای ساخت ویدیو
```

سرور Kavosh این فایل را مستقیماً می‌خواند و برای تغییرات، کافی است سرور را متوقف و دوباره اجرا کنید.

## ساخت تصویر و ویدیو
- **تصویر**: اگر `OPENAI_API_KEY` باشد از OpenAI استفاده می‌کند، در غیر این صورت از سرویس رایگان Pollinations.
- **ویدیو**: نیاز به `REPLICATE_API_TOKEN` دارد (مدل minimax/video-01 یا هر مدل دیگری که در `.env` تنظیم کنید).
